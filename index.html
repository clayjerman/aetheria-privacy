Kebijakan Privasi Aetheria

Aetheria: RPG Aksi Pixel Art, oleh Arrazy Inovasi. Berlaku sejak 23 Oktober 2026.

Kebijakan ini menjelaskan bagaimana game Aetheria ("Game") menangani informasi saat kamu memainkannya. Singkatnya: Game ini tidak mengumpulkan, menyimpan di server, atau membagikan data pribadimu.

Data yang kami kumpulkan

Tidak ada. Game tidak meminta pendaftaran akun, tidak memerlukan koneksi internet, dan tidak mengirim data apa pun dari perangkatmu ke kami atau ke pihak ketiga.

Data yang tersimpan di perangkatmu

  • Data simpanan permainan (kemajuan cerita, level, item, dan sejenisnya), dibuat saat kamu menyimpan di Kristal Astral.
  • Pengaturan seperti volume musik dan efek suara.

Data ini hanya tersimpan di penyimpanan internal aplikasi di perangkatmu, tidak dikirim ke mana pun, dan terhapus saat kamu menghapus Game atau menghapus data aplikasinya.

Izin perangkat

Game tidak meminta izin khusus seperti lokasi, kamera, mikrofon, kontak, atau akses ke file pribadimu.

Iklan, analitik, dan pihak ketiga

Game tidak menampilkan iklan dan tidak memakai layanan analitik atau pelacakan pihak ketiga. Pengunduhan dan pembaruan Game ditangani oleh Google Play sesuai kebijakan privasi Google.

Anak-anak

Game tidak secara sengaja mengumpulkan informasi dari siapa pun, termasuk anak-anak, karena memang tidak ada data yang dikumpulkan.

Perubahan kebijakan

Jika di masa depan Game menambahkan fitur yang memerlukan data (misalnya fitur online), kebijakan ini akan diperbarui terlebih dahulu dan tanggal berlakunya akan diubah.

Kontak

Pertanyaan tentang kebijakan ini dapat dikirim ke Arrazy Inovasi melalui arrazyinovasi.com.
