Kebijakan Privasi Aetheria

Aetheria: RPG Aksi Pixel Art, oleh Arrazy Inovasi. Berlaku sejak 27 Oktober 2026 (menggantikan versi 23 Oktober 2026).

Kebijakan ini menjelaskan data apa yang ditangani game Aetheria ("Game"), untuk apa, dan bagaimana kamu bisa menghapusnya. Game bisa dimainkan sepenuhnya tanpa akun.

1. Akun dan simpanan cloud (opsional)

Jika kamu memilih masuk lewat menu Akun & Cloud, kami memproses:

  • Alamat email dan kata sandi: untuk membuat akun dan masuk. Kata sandi dikelola oleh Firebase Authentication (Google) dan tidak pernah bisa kami lihat.
  • Simpanan permainan (kemajuan cerita, level, item, waktu bermain, dan ringkasannya): disalin ke cloud saat kamu menyimpan di Kristal Astral atau menekan "Simpan ke Cloud", agar bisa dipulihkan di perangkat lain.

Data ini disimpan di Firebase (Google Cloud) di wilayah Singapura, hanya bisa diakses oleh akunmu sendiri, dan tidak dijual atau dibagikan untuk iklan.

2. Iklan

Game menampilkan iklan berhadiah (misalnya untuk bangkit kembali atau memutar Roda Harian) melalui Google AdMob. Iklan hanya muncul jika kamu memilih menontonnya. AdMob dapat mengumpulkan ID iklan perangkat, alamat IP, dan informasi perangkat untuk menayangkan dan mengukur iklan. Di wilayah yang mewajibkan, Game meminta persetujuanmu terlebih dahulu, dan pilihan itu bisa diubah kapan saja di Pengaturan. Lihat cara Google memakai data.

3. Notifikasi

Game memakai Firebase Cloud Messaging untuk mengirim pemberitahuan seperti info pembaruan atau acara. Untuk itu perangkat diberi token notifikasi acak yang tidak berisi identitasmu. Kamu bisa menolak atau mematikan notifikasi di pengaturan Android.

4. Pemeriksaan versi

Saat menu utama dibuka, Game membaca informasi versi terbaru dari server kami agar bisa memberi tahu jika ada pembaruan. Pemeriksaan ini tidak mengirim data pribadi.

5. Data yang hanya tersimpan di perangkatmu

  • Simpanan permainan dan pengaturan (misalnya volume).
  • Status kecil per perangkat, seperti kapan Roda Harian terakhir diputar.

Data ini terhapus saat kamu menghapus Game atau menghapus data aplikasinya.

6. Menghapus akun dan data

Di dalam Game: buka Akun & Cloud → Hapus Akun. Akun dan simpanan cloud-mu langsung dihapus permanen. Jika kamu tidak bisa lagi membuka Game, ikuti petunjuk di halaman penghapusan akun.

7. Anak-anak

Game tidak ditujukan untuk mengumpulkan data dari anak-anak. Fitur akun bersifat opsional; jika kamu orang tua dan yakin anakmu membuat akun, minta penghapusan lewat halaman penghapusan akun.

8. Perubahan kebijakan

Jika cara Game menangani data berubah, kebijakan ini diperbarui dan tanggal berlakunya diubah.
